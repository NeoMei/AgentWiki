# AgentWiki v0.12.47 / Local Sync v0.13.1

修复复测反馈中的审核排序、重复返回入口和 MCP 页面更新参数丢失问题。

- 审核列表的新旧接口统一按创建时间倒序排列，同一时间按 ID 倒序；排序先于分页，避免按状态分组造成跨页时间错序。保留已有日期筛选规则。
- 来源、空间设置及来源内嵌的运行列表移除重复返回入口，继续使用空间顶栏导航；独立运行列表仍保留返回入口。
- Local Sync 为页面更新工具注册明确的命名参数 schema，保留顶层参数和旧 `__args` wrapper 的传递与兼容。原有授权、版本及目录并发校验不变。

Web/API/client 版本为 0.12.47；Local Sync 网关为 0.13.1，npm 包已正式发布，需要升级客户端网关才能使用新 schema。运行时上报、安装说明、接入计划和随包 skill 同步到 0.13.1；服务器继续接受 0.13.0 及此前受支持的客户端，保持其原版本和计划 hash。已发布的 sync protocol 0.6.1 保持不变，不重复发布。没有依赖升级或数据库结构、迁移变化。

尚未完成的 0.13.0 接入会话，请继续使用该会话原有的 `npx @neomei/agentwiki-local-sync@0.13.0` 命令完成。0.13.1 CLI 不恢复旧版本本地接入检查点；不要修改已保存会话的版本或计划 hash。此限制不影响服务端继续接受原版本会话。

本版本已完成独立审查、真实 SDK/HTTP 参数传递与拒绝后状态不变测试、隔离 PostgreSQL 审核分页排序验证，以及来源导航组件验收。个人单页中文、编辑目录定位与必填空白校验沿用 0.12.46 基线，本轮原线上回验通过。详细边界见[复测记录](verification/retest-20261017/acceptance.md)。

Obsidian 插件的附件超限提示和恢复诊断已独立发布为 0.5.12，官方资产与来源证明通过。Mac 隔离 Vault 验收不替代原 Windows Vault 回归；原 Windows 和原黄金书屋 wrapper 报错重放仍保留待验/未复现边界。

正式 npm 0.13.1 已发布并通过官方包逐字节与空目录安装验证；Web/API 已部署生产，1354 源码文件和 5 个公网入口资源摘要匹配，32 项 API 烟测通过。真实生产审核 10/14 的 53 条跨三页日期/全局倒序、10/15 的 5 条日期/倒序，以及来源/内嵌运行/设置桌面与 390px 导航回验通过。正式 0.13.1 网关已用顶层参数发布原反馈页更新，并完成 published 状态、全文精确回读与浏览器渲染验证。完整交付证据见[发布回执](verification/retest-20261017/release.json)。现存旧客户端进程不因 npm 发布自动升级。
