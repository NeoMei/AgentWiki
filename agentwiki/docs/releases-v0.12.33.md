# v0.12.33

知识图谱按参考图重做“关系网络”界面：文件夹作为画布内的分组边框，真实页面节点位于对应文件夹中，页面关系以曲线连接。统一顶部搜索和筛选工具栏，右侧展示选中页面的路径、打开入口及关联页面。

- 文件夹默认预览 5 个页面，可通过“更多”展开；优先展示关联较多的页面。空文件夹、未分组页面及文件夹已不可用的页面仍可查看。
- 支持按标题或路径搜索，以及全部、有关系、未连接、关系类型和来源筛选；“仅看关联”聚焦选中页面及其直接关联。修复关系类型筛选与“未连接”组合时的结果。
- 节点采用蓝色圆点、选中高亮和路径浮层；关联页面去重展示，关系与来源证据按需展开。手动关系与自动相似关系使用不同线型，保留关联创建、审批状态及删除入口。
- 保留单击选择、双击打开、节点拖动、画布平移、缩放及键盘访问。筛选改变分组位置后，拖动过的节点继续位于所属文件夹内；大图默认保留可读缩放，“适应图谱”可查看整体，选择页面后自动定位。

Web/API 0.12.33；Local Sync 0.13.0、协议 0.6.1 不变。没有服务器业务、数据库迁移或依赖变更；分组仅使用真实文件夹归属，不生成额外页面关系。

验证：完整客户端 156 文件 / 2,556 项测试通过，客户端构建（含 TypeScript）及 lint 通过；独立代码审查无未解决的 P1/P2 问题。使用实际图谱组件和隔离合成数据，浏览器已验证节点选择、关联详情、仅看关联、未连接与关系类型组合筛选、搜索空结果、文件夹展开、双击打开及创建关系后的详情读回。

补充浏览器验收：1404×790 桌面与参考图并排核对；390×844 窄屏文档宽度为 390，无横向溢出。95 页 / 18 组大图的适应图谱、继续缩小及末尾节点定位通过；实际节点拖动和画布平移、空图、空目录、缺失目录、未分组及中英文切换通过。最终新页面无 console error/warn。删除关系由现有组件测试覆盖，本轮浏览器确认框已取消，未记为浏览器删除成功。
