# AgentWiki v0.12.20

本版优化“我的知识空间”首页卡片，让每个空间在进入前就能看到关键上下文，延续 v0.12.19 的 Plane 风格页面改版。

## 变更

- 空间卡片展示页面数、成员数和最近更新时间，减少进入空间后再查找概况的步骤。
- 展示审核策略状态，区分“始终审核”和“限定范围自动发布”。
- 增加明确的“进入空间”入口，保留知识图谱与删除操作。
- 卡片在桌面三列和窄屏单列布局下保持可读，长名称、空描述和统计未返回时都有稳定回退。
- 列表接口类型支持 `updatedAt`、审核策略、成员和页面计数，为后续服务端丰富列表响应保留兼容空间。

## 验证

- Dashboard 定向测试、TypeScript、ESLint 和生产构建通过。
- 本地合成数据完成桌面与 390px 浏览器验收，卡片信息和跳转入口可见，窄屏无横向溢出。
- 正式发布与生产部署回执在 `docs/verification/space-cards-v01220-release.md` 记录。

## 版本边界

应用 root/server/client 版本为 `0.12.20`。Local Sync、同步协议、数据库迁移和用户正文保持不变；本版不发布 npm 或独立 Obsidian 插件。
