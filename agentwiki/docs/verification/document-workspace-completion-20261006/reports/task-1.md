## Implementation

- MarkdownWorkspace positions optionally carry frozen anchor/head coordinates for a nonempty main selection, including reverse direction.
- Exact source proof remains in a component-local WeakMap keyed by the bookmark object. A serialized/copied bookmark lacks proof, so router state never carries document or selected text for this feature, and a deserialized bookmark safely falls back to the semantic cursor.
- Restoration requires the original bookmark, identical complete source, and current page/Space/authorization identity scope. Scope changes clear proofs and pending restoration; returning to an earlier scope does not revive an earlier bookmark.
- A refused bookmark keeps existing clamped cursor/source-block/heading fallback. Selection-only restoration explicitly avoids undo history. No document writes are generated by capture or restoration.
- PageEditor carries the original bookmark back only when preview remains on the originating source block. Deliberate movement to a different preview paragraph wins. Page/user/Space changes clear the preview origin and pending position.
