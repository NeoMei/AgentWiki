# 内嵌 Agent 自动聊天验收（2026-10-19）

## 变更

基于目录访问修复 `519a7100`，移除问答、修改候选、直接修改的聊天模式选择。新请求统一为 auto：提问/总结/聊天草稿返回聊天结果；明确要求修改当前文章或在当前目录新建文档时，由服务端实际保存并返回链接。旧 question/proposal 历史保持兼容。

意图判定只接受最新用户指令及服务端提供的能力，不接受文档、引用或历史内容。模型不能选择任意目标，生成阶段只能维持已锁定操作或降级为回答；目录 MCP 工具仍然只读。

## 模型格式兼容

浏览器实测捕获了模型 summary 内部引号未转义的无效 JSON。保留严格校验，不修补生成正文；自动生成阶段至多允许一次同模型格式重试，保持已判定动作、权限和原截止时间，累计所有用量。补充 142 项运行器定向测试及独立复审。最终浏览器创建、修改、回答均通过正常 Worker 入口；只读账号仍明确拒绝保存。
