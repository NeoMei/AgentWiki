`resolvePackageManagerInvocation` 原先在 Windows 无条件访问 `WINDOWS_ENTRYPOINTS[manager].map`；Node 的绝对路径及不存在的可执行路径也进入该分支，导致三项进程测试提前崩溃。现在仅 npm/npx/pnpm 进行 JS 入口转换，其他命令及参数透传；不引入 shell。

仅修改 `scripts/package-manager-process.mjs` 与对应测试。新增 forced-win32 回归先失败后通过；实现者与独立审查均完成本地 17/17，独审 PASS、无必修项。实现 SHA256 `d7acea59b970af80b95742e8f93b56bb774a18738d410685afcaeaea70ba5c01`；测试 SHA256 `2c6e73834ef68c1f1b9cdf26cf7592323460e99ea32151c1e2b24b5f418837ee`。Windows 隔离 clone 同一补丁 17/17，exit 0（`exec-ed7e5c9f-b6c0-4723-9ef5-23547fe3706c`），CRLF 归一 LF 后两文件 SHA 精确一致（`exec-3ecf79f1-335f-49dd-895c-7fe53bbe7566`）。修复提交 `415f45f39070905a5cd919dd450d168d7e7115c8` 已推送并回读 origin/master；原发布 tag/线上版本未改写。
