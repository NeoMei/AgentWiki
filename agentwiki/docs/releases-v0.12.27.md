# AgentWiki v0.12.27

本版优化 Space 卡片的信息密度和响应式布局，让项目空间概览更紧凑、易扫读。

## 变更

- 去掉卡片固定最小高度，收紧内边距、图标、标题、描述、Owner、统计和更新时间之间的间距。
- 宽屏使用四列卡片布局，保留中屏双列和移动端单列。
- Owner 与审核策略标签支持截断，并保留完整悬浮提示。
- 图谱和删除操作在桌面端改为悬浮操作，移动端继续保持直接可用。
- 保留 Space Owner、页面数、成员数、更新时间和审核策略信息。

## 发布范围

- Web/API：`0.12.27`
- Local Sync：保持 `0.13.0`
- 同步协议：保持已发布的 `0.6.1`
- 无数据库迁移，不重复发布 npm 包。

- 客户端全量测试：151 个测试文件、2467 项通过。
- 客户端 TypeScript、lint、生产构建通过。
