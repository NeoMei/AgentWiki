# AgentWiki v0.12.29

## 目标

修复阅读页内置 Agent 只能回答、不能修改页面的问题。具备页面编辑权限的用户现在可以在 Agent 侧栏显式选择“直接修改页面”。Agent 仍先生成完整修改候选，客户端在写入前重新校验页面版本，并通过现有页面 CAS 更新保存；版本冲突不会覆盖人的新修改。

问答模式、只读用户、编辑器内的候选审阅与显式保存流程保持原边界。
