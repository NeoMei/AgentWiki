# AgentWiki v0.12.21

“我的知识空间”卡片现在展示页面数、成员数、审核策略和最近更新时间，延续简明的桌面三列、手机单列布局。

## 修复

- 最近更新时间取空间设置与活跃页面的最新时间。编辑页面正文后返回工作台，可以看到正确的更新时间。
- 新建空间响应直接提供页面数量，卡片立即展示 0 个页面和成员数量，不再停留在“统计同步中”。
- 时间聚合仅查询当前已授权、已分页的空间，排除删除页面，保持原有分页事务和兼容回退。

## 验证与版本

定向回归覆盖正文更新、空间设置更新、空空间、分页边界和新建卡片。完整门禁及正式部署结果见 [发布验收](verification/space-cards-v01221-release.md)。

应用 root/server/client 为 `0.12.21`。无需新增数据库迁移；Local Sync 与同步协议版本保持，本版不发布 npm 或独立 Obsidian 插件。
