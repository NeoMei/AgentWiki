# AgentWiki v0.12.30

修复中文界面系统单页协作仍显示英文、页面对比区域过小以及模板操作重复的问题。本版基于 v0.12.29 最新源码整合，保留阅读页 Agent 直接修改页面功能，并纳入现网已使用的“始终审核 / 无需审核”策略。

## 变更

- 系统单页模板以真实来源识别，任务、目标和待办显示对应界面语言；不覆盖自定义模板文本。
- 页面对比在居中大弹窗内展示，并保证审核及冲突处理操作可访问。
- 协作主页用于浏览和启动，复制、编辑、归档及新建集中到模板管理入口。
- “无需审核”允许现有写入权限内的 Editor/Publisher Agent 自动发布；Reader 只读，Agent 无人工审批权，目录与凭据限制保持。

## 范围

- Web/API：0.12.30；Local Sync：0.13.0；Sync Protocol：0.6.1。
- 无新增数据库迁移；不发布新的 npm 包或 Obsidian 插件。
- 10 月 14 日报告的 #2–#4 属于本次修复；#1 原报错流程待验，#5–#20 本轮未专项处理。
