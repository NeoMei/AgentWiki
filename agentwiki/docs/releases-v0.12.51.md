# AgentWiki v0.12.51

图谱改为更紧凑的响应式目录布局，节点标题、缩放适配、搜索定位和详情侧栏更易浏览。未建立关系的页面按真实状态显示，不生成虚构连线。

登录和注册入口在邮箱字段显示具体错误：重复邮箱提示“该邮箱已注册，请登录”并提供保留邮箱的登录入口；无效邮箱在提交前提示格式，服务端校验失败也定位到邮箱字段。中文与英文提示随语言切换更新。

Web/API/client 为0.12.51，保留线上0.12.50已发布的通用MCP和WorkBuddy接入修复。Local Sync保持0.13.4，protocol保持0.6.1；没有新增依赖、锁文件变更或数据库迁移。

发布前验证及线上验收结果见 [发布回执](verification/graph-auth-release-20261019/release.json)。原测试报告的三项开发回复保留独立状态，不替测试人员填写回归结论。
