# AgentWiki v0.12.19

本版统一内置项目管理、软件开发和协作模板的页面布局，采用紧凑列表、清晰分栏、细分隔线与简明的文档排版。

## 变更

- 模板目录、详情与结构预览统一视觉层级，保留空白页面、单页模板、页面组及 Space 自定义模板。
- 协作配置、角色绑定和启动向导统一排版；新增流程摘要支持系统模板本地化，历史快照与自定义名称保持来源边界。
- 协作运行的任务、审核、产物与活动面板统一间距；长标题和暂停原因不会挤掉任务区。
- 任务看板统一工具栏、状态与详情样式，保留图布局及里程碑定位。
- 文档阅读统一标题、段落、表格和引用样式；相同的页面标题与开篇 H1 只显示一次，Markdown 原文与交互源偏移不变。
- 保留滚动时可访问的文章目录入口。
- GitHub 源码同步已在生产运行的 Agent 长候选/局部提案修复和依赖加固；发布前逐文件核验服务器，后端、包与锁文件已与候选一致。

## 验证

- 本次改版完成三轮独立任务及代码审查，无未关闭发现。
- 改版候选客户端 141 文件 / 2254 项测试通过；另有 159 项独立定向测试通过，TypeScript、ESLint 和构建通过。
- Chrome 本地实际组件与真实系统模板定义验收通过，覆盖桌面、390px、1024px、中英文、配置与启动、管理筛选、文档编辑。合成 API 证据与正式部署验收分开记录。
- 正式发布提交的全仓检查、备份与生产回读另记部署回执。

## 版本边界

应用 root/server/client 版本为 `0.12.19`。Local Sync 保持 `0.11.0`，协议保持 `0.6.1`；本次不发布 npm 或独立 Obsidian 插件，不新增 Prisma migration，不覆盖现有模板版本或用户正文。
