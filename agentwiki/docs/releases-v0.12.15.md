# AgentWiki v0.12.15 发布记录

## 修复

阅读页滚动时会更新侧栏位置。Markdown 内联渲染组件随每次更新重新创建，导致图片组件被卸载、Blob URL 被释放、附件请求重启；因此已经显示的图片会再次变成文件名占位框。

本版将 Markdown 渲染组件固定为稳定的组件类型，通过 Context 更新任务交互和选文状态。滚动、侧栏位置更新不再卸载图片，加载中的请求也继续完成。此修复同时覆盖 Wiki 图片、列表、Callout 与链接内的图片。

图片仍在引用解析完成后立即发起受保护的附件请求，不等待滚动。首次网络传输未完成时仍保留正常加载状态。本版没有新增共享 Blob 缓存，也没有改变附件权限。

应用版本为 `0.12.15`；Local Sync 继续为 `0.11.0`，同步协议继续为 `0.6.1`。无需数据库迁移或 Obsidian 插件更新。
