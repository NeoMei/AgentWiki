# Agent 一次接入与按空间实时授权

状态：实现候选；尚未发布或迁移生产。用户于 2026-10-13 明确纠正设计。

## 目标

Agent 接入一次 AgentWiki。凭据标识 Agent 和连接生命周期，每个请求按实际目标 `spaceId` 读取该 Agent 的当前授权。新增、降级或撤销某空间授权，不要求本机重新接入，不影响其他空间授权。

本设计替代 2026-10-03 多空间网关设计中的“一凭据绑定一个 Space Grant”约束，以及 2026-10-09 成员委派计划中保留该约束的部分。一个本地 MCP 网关的约定不变。

## 权限模型

| 对象 | 职责 | 不承担的职责 |
| --- | --- | --- |
| AgentCredential | 验证同一 Agent 身份，检查过期、撤销及凭据所属关系 | 不保存目标空间、角色或权限快照作为访问上限 |
| AgentGrant | `agentId + spaceId` 的实时角色和目录权限 | 不控制身份凭据的存活；删除 Grant 不级联删除 Credential |
| spaceId | 每次请求的明确目标 | 不作为本机已安装空间白名单，不通过另一个 Agent 的凭据重试 |
| Space policy | 对发布、来源、协作等领域动作施加治理约束 | 不被 Publisher 角色或旧成功记录绕过 |

每次鉴权仍检查凭据、Agent、所属用户与目标空间的有效状态；角色从目标 Grant 计算。A 空间 Publisher 不能为 B 空间 Reader 提供写权限。Agent 仍不能审批 ChangeSet 或管理人类成员。

读取只提供 `pageId` 或 `runId` 的接口应先解析真实所属空间，再应用同一鉴权。MCP 外层显式 `spaceId` 与对象真实空间不一致时应拒绝，不能悄悄改目标。

## 接入与兼容

- 本机配置继续保留一个 `agentwiki` MCP 入口。已选择的连接限定同一 Agent、服务端和客户端；不跨身份自动切换凭据。
- `list_spaces` 返回服务端当前有效 Grant。新增授权后下一次调用即可发现，不依赖本机配置、重新安装或进程重启。
- 存量 `spaceId` 只可作为默认上下文，不能作为凭据授权边界。调用显式 `spaceId`，并发请求不能共享一个可变的当前空间。
- 旧安装 API 可保留 `spaceId` / `role` 作为首次 Grant 创建及默认上下文。响应标记 `credentialScope: agent`；后续授权从实时 Grant 读取。
- Access 响应将 Agent 的 `grants` 与 `credentials` 分开。凭据不再返回单一 `authorization` 对象作为权限说明。
- 本地知识目录和确认 Preview 继续按空间隔离。Agent 知识提交使用同一 Agent 身份；不能把某个空间的人类同步设备凭据复用到另一个空间。

## 数据迁移

解除 `AgentCredential` 到 `AgentGrant` 的强制外键和级联删除关系。保留现有凭据 ID、散列、安装幂等标识、过期和撤销状态。已删除或撤销的凭据不恢复，也不合并多份旧凭据。历史绑定仅可保留为审计信息，不参与鉴权。

迁移后，尚有效的旧 Agent 凭据依据同一 Agent 的现有实时 Grants 工作。这是本次明确的权限语义变更，应与服务端、网关和接入说明协调发布；生产迁移需要既有发布流程中的数据库及应用备份。旧服务端依赖旧模型，不能仅回退应用文件而忽略数据库兼容性。

## 必须通过的行为

1. 一个连接访问 A 与 B，按各自角色执行；无 Grant 的 C 拒绝。
2. 运行中的网关新增 C Grant 后直接发现并访问；不增加本机连接。
3. 撤销 A 或删除 A，B 保持可用；恢复 A Grant 后使用当前角色。
4. A 降为 Reader 后即刻拒绝写；B 的 Publisher 权限不能被借用。
5. 撤销/过期凭据、停用 Agent、锁定/删除所属用户时全部空间拒绝。
6. 同一用户的另一 Agent、另一服务端或另一客户端连接不能作为拒绝后的替代身份。
7. 异步来源运行、协作任务提交和审核发布重新校验实时权限，保留现有事务锁和冲突保护。
8. 迁移前凭据迁移后保留状态；Grant 删除不再级联删凭据。
9. 前端区分身份凭据、目标空间授权和当前客户端连接验证；新增空间授权不要求重复接入。暂停 Agent 不显示可访问，Reader 不进入执行准备，凭据列表不因旧字段移除崩溃。
10. 本机知识目录、Preview、同步提交按 `spaceId` 隔离；人类同步设备授权保持原有边界。旧 Tree v2 目录和未同步编辑原样保留，Agent 知识状态使用独立目录，异常/丢失基线明确拒绝。
