# 首页、使用指南与工作台统一导航设计

## 目标

让首页 `/`、使用指南 `/guide`、工作台 `/dashboard` 之间始终可以直接、可预测地跳转，消除当前因登录态、隐藏菜单和 Logo 目标不一致造成的混乱。

## 现状问题

- 首页在未登录时只显示“使用指南”，登录后只显示“进入工作台”，两个入口互斥。
- 使用指南顶部只有“返回首页”，工作台入口位于长页面底部。
- 工作台 Logo 跳到 `/dashboard`，首页和指南隐藏在个人菜单中。
- 未登录访问工作台会无提示地重定向首页，用户不知道为何没有进入工作台。
- 工作台中的“知识空间”和“工作台”实际指向同一路由，继续并列会产生重复入口。

## 选定方案

采用共享的顶层导航组件，在三个页面中统一呈现“首页 / 使用指南 / 工作台”。组件负责路由、登录态目标、当前页面状态和响应式显示；各页面保留自己的业务操作区域。

## 导航规则

| 入口 | 已登录目标 | 未登录目标 |
|---|---|---|
| 首页 | `/` | `/` |
| 使用指南 | `/guide` | `/guide` |
| 工作台 | `/dashboard` | `/?intent=workspace#login` |

- AgentWiki Logo 在三个页面中始终跳转 `/`。
- 当前入口使用明确的视觉选中状态，并设置 `aria-current="page"`。
- 首页和使用指南使用完整文字标签。
- 工作台顶部空间较紧，移动端允许隐藏文字但必须保留图标、可访问名称和标题。
- 工作台原有 `/agents`、`/review`、搜索、语言和个人菜单继续保留。
- `/dashboard` 本身就是知识空间总览，因此统一显示为“工作台”，不再同时放一个重复的“知识空间”入口。
- 个人菜单移除重复的“使用指南”和“关于”入口；Profile、集成和退出保持不变。

## 未登录工作台流程

1. 用户在首页或使用指南点击“工作台”。
2. 共享导航跳转到 `/?intent=workspace#login`。
3. 首页读取 `intent=workspace`，将登录卡滚动到视口并聚焦邮箱输入框。
4. 登录卡显示中英文提示：“登录后进入工作台”。
5. 登录成功后继续沿用现有行为进入 `/dashboard`。

直接访问受保护路由但未登录时，`ProtectedRoute` 也使用同一个带意图的首页地址，避免静默跳转。

## 组件边界

### `GlobalNavigation`

- 新增共享组件，集中定义三个顶层入口。
- 读取当前路径、语言和认证 token。
- 统一计算工作台链接目标和活动状态。
- 支持公共页与工作台两种密度，但不复制路由判断。

### `ProductPage`

- 使用共享导航替换当前登录态互斥按钮。
- Logo 改为首页链接。
- 登录卡增加稳定锚点、提示和邮箱输入框引用。
- 读取工作台访问意图并执行滚动与聚焦。

### `UsageGuide`

- 使用共享导航替换单独的“返回首页”。
- 保留语言切换器和现有内容布局。

### `Navbar`

- Logo 改为首页链接。
- 使用共享导航呈现首页、指南和工作台。
- Agent、审核、搜索、个人菜单继续作为工作台业务导航。
- 删除个人菜单里的重复首页/指南入口。

### `ProtectedRoute`

- 未登录时重定向到 `/?intent=workspace#login`，并使用 `replace` 避免返回键进入重定向循环。

## 视觉与可访问性

- 沿用现有白底、灰色边框和蓝色活动态，不引入新的组件体系或视觉语言。
- 链接使用统一高度、圆角、悬停和焦点环。
- 活动状态不能只靠颜色；同时使用字重或浅色背景。
- 图标链接必须保留可访问名称和 `title`。
- 桌面端验证三个入口完整可见；移动端验证无溢出、遮挡和重复入口。
- 所有新增文案同时提供简体中文和英文，并继续由共享语言上下文控制。

## 测试与验收

### 自动化测试

- 共享导航在已登录状态下生成 `/`、`/guide`、`/dashboard` 三个入口。
- 未登录状态下工作台入口生成 `/?intent=workspace#login`。
- 三个路由的当前入口具有 `aria-current="page"`。
- `ProtectedRoute` 未登录重定向携带工作台访问意图。
- 首页收到工作台访问意图时显示提示并聚焦邮箱输入框。
- 使用指南和工作台导航不再把首页/指南藏在个人菜单中。

### 浏览器验证

- 已登录：`首页 → 指南 → 工作台 → 首页` 往返正确。
- 未登录：`指南 → 工作台` 到达首页登录区域，提示和焦点正确。
- 中英文切换后导航标签和提示一致。
- 桌面与移动端均无横向溢出、遮挡、重复入口或控制台错误。

## 不做

- 不改认证接口、登录凭据或服务端权限。
- 不重做首页、指南或工作台内容布局。
- 不引入第二套组件库。
- 不新增独立的第二层全局顶栏。
