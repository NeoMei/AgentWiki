# AgentWiki v0.12.17 发布记录

本版汇总 10-08 测试报告对应的六组修复。网页应用版本为 `0.12.17`；Obsidian 同步修复由独立插件 `0.5.7` 提供。Local Sync 保持 `0.11.0`，同步协议保持 `0.6.1`，这两个包相对 `v0.12.16` 没有源码变化，本次不发布 npm 包。应用不需要新增数据库迁移，Space 权限与允许列表保持不变。

## 修复

1. **目录、菜单与错误提示**：目录和图谱的权限错误按界面语言显示；全局搜索统一保留在顶栏，目录继续提供过滤及字面量匹配高亮；折叠目录后空间名仍可读。目录操作菜单支持跨树互斥、点外和 Esc 关闭，修正菜单遮挡下一行操作入口的问题。
2. **编辑器与 Agent 对话**：稳定长文编辑时的 CodeMirror 扩展和装饰更新，减少滚动及格式显示跳动，保留显式保存、Undo/Redo 和中文输入组合契约。本人发送消息及接近底部时的新回复会跟随滚动，上翻历史时保留阅读位置。
3. **模板与绑定能力**：分开表达保存 Agent 绑定、启动页面协作及保存目录模板的能力。具备权限的用户可独立保存绑定；受允许列表限制的启动或模板保存入口显示实际可用性和原因，后端授权不放宽。
4. **协作运行与审核**：根据可信系统模板来源本地化任务、目标、Todo、审核标准和产物名称，保留用户文本及 Agent 名称。待审核项前置，操作置于卡片头部；预检测到页面冲突时保留恢复、返工和终止等安全动作，冲突或比较条件不满足时仍禁止批准。修正长文本卡片在桌面及移动布局中的边框和溢出问题。
5. **图谱与来源导航**：图谱默认隐藏节点标签，选中后只显示当前节点名称，保留缩放、双击等交互。来源页统一承接来源和运行两种视图，旧运行列表及详情深链接继续有效，跨来源运行列表、重试、取消及权限隔离保持。
6. **Obsidian 父节点合并与映射目录**：配套插件修复本地删除父目录、远端新增子节点时的三方合并边界，避免形成缺失父节点的结果，保留冲突确认和用户选择。验证已有的嵌套映射目录自动创建、目录复用及文件占位错误提示；该实现位于独立插件仓库，未修改网页同步协议。

协作系统文案的 lookup 映射随运行面板按需加载，移出首屏静态依赖；225 条映射及中英文各 229 条翻译保持不变，首屏脚本预算仍为 550000 字节。
