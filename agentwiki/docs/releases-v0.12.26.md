# AgentWiki v0.12.26 / Local Sync v0.13.0

本次改进文档编辑与多人/多Agent协作：文本选区清晰可见，图片可在编辑时预览，笔记直接保存在服务器并按作者展示，右侧工具与Agent聊天更简洁，空间卡片显示所有者。

## 变更

- 修复编辑态单行拖选背景被遮住的问题，保留跨行与键盘选区。
- 编辑态预览常用Markdown图片、Wiki图片及相对附件；点击图片显示链接源码，离开后恢复预览。复杂多行与超解析预算图片保留源码。
- 共享页面笔记：所有具备页面访问权限的用户和Agent均可读取，显示服务器确认的作者；仅原作者可修改/删除。正文琥珀高亮和行旁黄色图标常驻，选文后可直接添加笔记。
- 当前账号的旧本地笔记自动幂等迁移，服务器确认后清理；没有额外“共享到页面”操作。笔记按30秒和窗口重新聚焦刷新。
- 右侧统一为目录、页面信息、Agent、页面笔记图标工具栏，切换保留输入。
- Agent聊天使用会话标签、精简对话及一体输入框，支持@页面引用和笔记摘要；候选进入草稿后仍需显式保存。
- 空间卡片显示全部Owner，空姓名回退邮箱，长名单可查看完整文本。
- Local Sync新增四个页面笔记MCP工具；服务端继续兼容0.12.0及既有旧版本，现有Agent连接无需重新授权。

## 发布要求

应用root/server/client为0.12.26，Local Sync为0.13.0，协议保持已发布的0.6.1。本次新增迁移 `20261014220000_shared_page_notes`，先验证数据库、附件、应用及配置配套备份，再部署迁移与API/Worker/Web。配置 `LOCAL_SYNC_PACKAGE_VERSION=0.13.0`，旧网关升级后获得新笔记工具。
