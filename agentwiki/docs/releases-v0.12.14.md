# AgentWiki v0.12.14 发布记录

## 范围

这是一次兼容的客户端补丁版。受保护的 Markdown 图片在 Blob 请求返回前会按服务端提供的原始宽高保留布局，不再塌缩成只有文件名的窄占位卡；图片请求完成后仍使用受保护的 Blob URL 和现有放大预览流程。页面内容、附件权限、Local Sync、ACP 和同步协议契约均未改变。

应用版本为 `0.12.14`，Local Sync 继续为 `0.11.0`，同步协议继续为 `0.6.1`。
