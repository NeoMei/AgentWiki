# v0.12.34

修复文章右侧 Agent 多会话标签只能增加、无法关闭的问题。每个标签提供关闭按钮，也可使用 Delete；关闭当前标签后选择相邻标签，全部关闭后进入新会话空态。

- 会话仍保留在历史中，可重新打开；同一页面生命周期内未发送的输入保留，关闭标签不会取消服务端运行任务。
- 打开标签与选中状态按用户和空间隔离保存，刷新后不会自动恢复已经关闭的标签；浏览器存储不可用时仍可在内存中操作。
- 阅读与编辑页切换保留打开状态；窄屏下选中标签连同关闭按钮滚入可见范围。
- 修复首次历史列表尚未返回时关闭标签的竞态、新建请求中的切换竞态，以及首次发送后关闭标签导致已发输入再次出现的问题。

Web/API 0.12.34；Local Sync 0.13.0、协议 0.6.1 不变。无服务器业务、数据库迁移或依赖变更。

验证：93 项相关测试、客户端构建（含 TypeScript）、相关 lint 及独立代码复审通过；Chrome 实际组件验证桌面/窄屏关闭、历史重开、草稿、Delete 焦点、阅读/编辑切换、刷新空态以及运行任务继续完成。完整客户端 2572 项通过，1 项知识图谱适应缩放测试失败；相同失败已在完全未改动的 v0.12.33 基线中复现，单独运行该图谱套件 13/13 通过，本次不修改图谱。
