# 组件复用规则

- 公共组件优先从统一复用源克隆，不从旧页面临时硬拽
- 如果某个公共模块已经被两个以上页面复用，则它应被视为稳定公共组件
- 组件来源、标准版本、可复用范围，应写入本文件或对应任务 refs，不要散落在 current 中

## 下拉选择控件

- 产品表单和筛选统一使用 `agentwiki/apps/client/src/components/NativeSelect.tsx`，保留原生键盘、标签、校验与表单提交语义。
- 外观集中在 `NativeSelect.css`：桌面32px、移动端至少44px、8px圆角、14px字号、统一箭头与轻量可见焦点；高对比模式恢复系统控件和可见焦点。
- 使用处的 className/CSS 只控制宽度、间距和 flex 等布局，不另写箭头、边框、内边距或聚焦轮廓。多选/列表框由共享组件处理，不添加第二套视觉实现。
- ESLint 禁止产品 JSX 直接写 `<select>`；只有共享组件实现和测试夹具豁免。规则自身测试验证会拒绝新增裸控件，浏览器回归检查实际尺寸、切页、聚焦与高对比表现。
- 操作菜单、搜索建议和按钮式弹出菜单保留各自语义；这些模式的修改仍须检查既有组件和展开/聚焦/窄屏状态，不能以单元测试替代视觉验收。
