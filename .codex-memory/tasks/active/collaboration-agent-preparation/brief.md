# 协作映射内准备 Agent

## 目标

修复协作运行“映射 Agent”在没有已授权可执行 Agent 时无法继续的问题，使 Owner/Admin 能在同一向导内选择或创建 Agent、恢复状态、授予当前 Space 执行角色、生成 MCP 接入指令、确认接入并完成当前 Role Slot 映射。
