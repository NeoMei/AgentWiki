# 决策

- 用户明确指定交互：编辑态看图，点击图片看链接；不增加侧边预览面板。
- 普通 Markdown 图片与 Wiki 附件统一交互。未聚焦时首行图片也需显示；光标进入图片所在行时显示源码。
- 采用真实 Markdown 解析结果，保留 URL 转义/标题及原文位置；代码中的图片不渲染。
- 多行图片需遵守 CodeMirror 插件装饰的跨行限制，无法直接替换时保留完整源码。
- 安全规则与附件鉴权复用阅读态逻辑，不直接拉取未解析相对附件。

# 个人笔记显示规则（2026-10-14 用户补充）

- 最终用户纠正为常驻显示：阅读、编辑及编辑页预览的文字高亮和行旁黄色气泡始终显示；工具栏“个人笔记”只切换面板。此前短暂提出的“面板打开才显示”已撤回。
- 参考截图中的黄色行旁图标是明确需求，不能只用文字高亮代替。
- 标记与卡片双向定位；重叠笔记可依次访问；不等同于发送复选框，不自动交给 Agent。
- 只展示当前账号/Space/页面私人笔记，严格复用原文锚点解析，不改变发送和接受的安全证明。
- 笔记面板借鉴参考图：紧凑筛选和数量，每张卡片顶部为勾选/状态/定位，灰底原文引用，下面为笔记内容。
- 新增笔记也借鉴参考图：有效选文旁出现添加入口，点击后就地弹出输入框，保存后即时显示标记；保留现有面板入口。
