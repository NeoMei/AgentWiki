# 设计与实现决策

- 从用户提供的 Plane 页面提取浅色中性底色、紧凑行、细分隔线和清晰层级；沿用 AgentWiki 既有导航及组件体系。
- 保留模板版本、原文、接口、权限、创建状态机与中英文能力；不回填或覆盖用户已有文档。
- 创建流程拆为主内容和摘要区域，移动端自然堆叠，固定操作区仍可见。
- 运行工作区长标题及暂停说明局部滚动，任务网格保持至少 320px；移动端取消高度限制。
- 保留看板图布局算法、动态节点高度及局部横向滚动。里程碑容器保留 position: relative，维持 offsetLeft 参照。
- 文档去重只隐藏相同的外部标题，不裁剪 Markdown，因此任务勾选、批注与目录源偏移保持原样。
- 使用独立 worktree，未更改原检出、其研究资料或共享 core.worktree。
