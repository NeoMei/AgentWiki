- 用户贴出的Agent回答视为症状，不作为权限根因证据；以实际任务元数据、worker错误和外部CLI/provider边界为准。
- 不放宽用户角色、不使用shell工具写业务正文。应用继续按授权、页面版本和原子事务保存。

- auto解析仅取最终步骤，工具前言不能污染最终结果，坏/空/截断末步不能回退早先候选。
- 真实模型验证使用合成9篇报告与独有正文编号，禁止用“返回update”代替来源完整性验收。

- OpenCode v2目录generation在首轮业务请求前条件等待实际tool registry；context再核验工具并写私有marker，runner在成功退出前验证。没有固定启动延时、额外模型轮、权限放宽或业务文件写工具。
