- 服务端授权无需再次修改：SSH 只读确认 codex Agent 已有目标 Space editor。
- 访问失败直接由当前 Codex 仍运行旧 workbuddy Agent 连接导致。提示词混杂与热重载假设是本轮要修的产品问题；不能将所有历史身份来源归因于提示词。

- 当前工具拒绝控制 Codex 自身，无法代用户重启；不通过其他 UI 或进程终止绕过工具限制。
- 保持现有 0.13.4 安装，代码新功能未冒充已发行；正式发布需要新版本。
