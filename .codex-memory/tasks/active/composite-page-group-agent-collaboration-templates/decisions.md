# 已确认决策

1. 采用 A+：统一组合 TemplateVersion，保留内容树、协作运行和 ChangeSet 审核三个独立运行时。
2. 新建入口区分单页面和多页面模板；协作开关默认关闭。
3. 多页面模板创建真实 Folder/Page 树；Folder 不绑定 Agent。
4. Page 可长期绑定一个主责 Agent；绑定不授予权限，活动 Run 冻结负责人。
5. 本次参与 Agent 由启用任务负责人计算，不自动纳入所有历史绑定 Agent。
6. 页面目标任务创建 Artifact + ChangeSet，并由一次人类审核原子发布。
7. 模板实例化全有或全无，只推进一次内容树 revision。
8. 现有目录可裁剪后保存为 Space 模板；具体 Agent 抽象为 Role Slot。
9. 首期不复制附件，不修改图片引用或 Sync v3。
10. 旧单页自动兼容；系统协作模板发布组合新版；Space 自定义旧流程显式升级。
11. 旧“项目管理”单页保留历史引用但退出新建目录，由“项目管理工作区”替代。
12. 每个执行阶段生成每个参与 Agent 一份合并提示词。流程开始及人工审核后的恢复阶段分别需要用户明确唤醒，沿用 waiting_human/paused 安全退出协议，不承诺自动远程唤醒。
13. 保存长期绑定与启动本次协作相互独立；本次角色覆盖不改写已有页面默认负责人，批量替换须显式选择页面。
14. 当前验收仅本地隔离环境；GitHub push、npm 发布、合并共享分支和生产部署均需各自授权。协议 fixture、真实模型调用、浏览器持久化及全量测试分别记证据，不能相互冒充。
