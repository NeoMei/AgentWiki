# 决策

- 用户最终明确“所有有权限成员可见，按作者区分”，随后明确不需要“共享到页面”操作；不增加可见性开关。
- 作者由服务器鉴权确定，不接受客户端冒充作者；卡片使用保存的作者姓名、人类/Agent 类型与当前作者“我”标识。
- 新笔记直接服务端保存；旧数据按当前账号和页面自动迁移，clientNoteId 幂等、软删除墓碑防复活。
- 修改使用 expectedUpdatedAt；笔记不改变 Markdown 或页面更新时间。锁顺序加入现有 Space advisory 边界，避免和改标题死锁。
- 客户端使用账号/Space/page/generation/请求 epoch 阻止旧回执；权限失败清内容并废止排队操作，后续重新授权的新读取可以恢复。
- 四个图标标签上方导航常驻，关闭只收起面板。切换保留草稿，键盘箭头不聚焦 Agent 输入；显式快捷键可聚焦。
- 琥珀文字高亮和行旁黄色气泡在阅读及编辑状态常驻，不依赖笔记面板开关。
- 已提交的笔记状态写入跨普通路由切换完成，新页面先等待同 scope 回执再读；账号/token 切换或明确失权撤销。PATCH 15 秒超时，鉴权拦截器后再次检查原 token。
