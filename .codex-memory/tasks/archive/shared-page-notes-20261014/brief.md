# 页面共享笔记与统一侧栏

## 目标

笔记直接保存在服务器，所有有页面访问权限的用户和 Agent 可见、按作者区分；无需另行分享。右侧用一排图标切换目录、页面信息、Agent、页面笔记。

- 真实 PostgreSQL、REST 和 MCP SDK 七项门禁通过；client 最终 151 files / 2434 pass，server 3156 pass，protocol 140 pass，local-sync 998 pass，runtime 309 pass；全部 239 项 DB 门禁均有通过回执（初次构建干扰两项已定向补跑）。类型检查、lint 和构建通过，6 项既有 skip 未计为通过。
- 真实 Chrome 本地 fixture 验证新增、跨账号可见及作者不变、human/Agent 区分、桌面读写高亮与黄色图标、390px 正常排版、键盘工具切换、Agent 草稿保留。

## 实现边界

- 只迁移当前账号、Space、页面的本地旧笔记；服务端确认幂等保存才清理旧记录。
- 人类页面成员可注释；Agent reader 只读、editor/publisher 写入；只有作者可修改或删除自己的笔记。
- 正文编辑/应用候选仍受 canEdit 限制。笔记共享不等于自动发送 Agent。
- 保留现有笔记状态/回执流程；没有额外扩展正文编辑和删除笔记 UI。
