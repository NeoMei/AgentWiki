# 决策

## 当前有效约束

- 默认 generic，支持具有本地 stdio MCP 能力的宿主；不猜未知配置路径。generic 导出 `~/.config/agentwiki/mcp.json`，WorkBuddy 使用 `~/.workbuddy/mcp.json`，保留旧三客户端快捷项。
- Node24/26 在授权/换码/写状态前检查；仅自动打开同源授权 URL。浏览器启动不等于用户授权，授权后用 continue 按返回间隔轮询，CLI status 只读本地检查点。
- 浏览器授权、客户端 MCP/工具信任、完整重启或重载、新会话真实读页分别记证。测试注入浏览器依赖，真实 opener 必须零调用。
- 同名未知 MCP 先拒绝；用户保留或重命名冲突条目后继续原 session，不重建身份。doctor 可选宿主缺配置为 unverified。
- JSON steps 与 legacy checkpoint 持久化根级精确包版本；缺失或不匹配 marker 在推进、远端请求或 token 清理前拒绝。旧会话按原启动命令的精确版本继续，不补写 marker/version/planHash；历史诊断保持只读。
- npm 正式 metadata、tarball 和空缓存安装都通过才算发布可用，publish exit0 单独不足。生产源码冻结，后续文档不改变已发布源码和包。
- 密钥验证由用户在真实认证页完成，不索取或输出密码、OTP、私钥；认证中断不撤销已有发布授权。
- 协调备份需配套数据库/应用/配置/附件并恢复 writers；不得自动恢复覆盖快照后的用户写入。未做恢复演练不得称恢复能力已实测。
- 私有截图、页面正文、原始完整日志、凭据和备份不提交；旧错误与阶段结果不由新成功记录覆盖。
