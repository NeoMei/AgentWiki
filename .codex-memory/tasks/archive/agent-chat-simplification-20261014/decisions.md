# 决策

- 用户截图作为已选定视觉方向，直接改真实产品组件，不再要求额外设计确认。
- 去掉会话下拉表单和每轮对话外层卡片；顶部 tabs/新建/历史，用户消息浅灰气泡，Agent 回复保持白底。
- 底部只常驻输入、模式和发送/停止；引用/笔记摘要与当前文档上下文可见，范围及完整快照按需展开。
- 使用现有数据与权限。切换模式不自动发送；候选仍先进入草稿再由用户保存。
- 回归重点：会话草稿、@ 引用与键盘、中文输入法、停止/失败恢复、笔记生命周期、切页和只读权限。

- 引用浮层使用 Portal 并按侧栏与可视窗口共同限位，账号/token切换或隐藏立即关闭。
- 多附件时限制composer高度并分别滚动引用/笔记，保留输入、发送和错误；不丢上下文以换取整洁。
