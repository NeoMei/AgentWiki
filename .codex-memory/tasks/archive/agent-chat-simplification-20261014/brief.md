# 内嵌 Agent 聊天界面简化

## 目标

根据用户提供的截图改造真实 AgentSessionPanel：顶部轻量会话标签、中间对话、底部一体输入框。引用和笔记用摘要附件，低频设置按需展开，降低表单密度。

## 范围

- 保留问答/修改候选、目标范围、来源快照、笔记回执、候选审阅及显式 Save 权限边界。
- 增加紧凑引用弹窗及 @ 入口；保留同 Space、最多五篇和异步请求隔离。
- 复用现有组件、图标、系统字体及中英文文案；不新增模型后端或虚构模型选择器。
- 本地实现与验收；不推送、部署或发送真实 Agent 请求。
