# 决策

- 正式仓库直连 GitHub，保留旧本地库为显式恢复入口，避免中转引用产生错误 ahead/behind 结论。
- 旧主目录有进程和关联 worktree 依赖，不改名、不移动。将现有工作状态固化为本地 archive 分支，更新交接指向正式入口。
- 先保存原配置、index、工作补丁、未跟踪文件、登记与 SHA-256 清单，再修改本地状态；恢复分支不设置远程 upstream，不推送。
- 其他 8 个历史 dirty 工作树仅创建恢复 ref，不改变其 HEAD/index，避免干扰其他聊天。
- 不回放旧 DTO trim 方案：正式服务拒绝用户名/密码任意空白，旧预处理会改变现行规则；旧登录补丁也会改变既有密码兼容性。
- 已不存在的登记可 prune；现存历史目录含 ignored 验收资料和独有提交，保留原位。
- 不安装依赖、不改运行代码，不为本地 Git 配置/文档调整重跑应用全套测试；使用 Git 状态、对象校验、恢复验证和发布 guard 验证。
