# 决策

- 复用上一轮已获认可的逐项评估；不重复需求审批。
- 根据现行授权实现、迁移规格与回归测试，每个 Credential 绑定一个 Space Grant。多空间报告通过接入文案澄清处理，不把凭证权限扩大到 Agent 的全部 Grant。
- 重复内容仅作审核风险提示，不统一禁止合法同正文页面。
- 自动合并保留双向删除语义；恢复服务器内容必须是明确选择。
- 并行实现采用不重叠文件范围，协调者串行提交，独立审查后再集成。


- 新建与显式改名的非空白标题规则下沉到服务/发布边界，覆盖HTTP、MCP、知识包；历史异常页content-only保存及历史恢复不自动改名。
- 重复正文在一次参数化集合查询中选取各组元数据，每候选最多五例；不按候选串行扫Page，不返回既有正文。
- 插件事务持久化隐藏目录枚举模式，准备/执行/恢复一致；仅在严格reader白名单接纳已定义布尔字段，未知字段仍拒绝。
